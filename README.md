# Loja EKKLESIA

Loja online da EKKLESIA, publicada em https://ekklesiastoreide.com.br (GitHub Pages).

- **Não edite `data/` e `img/` à mão.** Esses arquivos são publicados pelo **EKKLESIA STUDIO** (menu "Loja online", botão "Publicar na loja"). Ele envia os produtos ativos, as fotos e as configurações.
- Pagamento por **Pix** (BR Code gerado no navegador): o cliente escolhe entre a entrada (padrão 50%) ou o valor total. Depois envia o pedido e o comprovante pelo WhatsApp.
- Os itens do carrinho e os pedidos ficam no aparelho do cliente (localStorage). Não há servidor nem banco de dados.
